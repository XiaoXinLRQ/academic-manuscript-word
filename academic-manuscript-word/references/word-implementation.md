# Word 原生实现细则

## 标题主题覆盖预防

在新建文档初始化、内容写入前执行；使用集中配置中的字体与颜色，不新增分散常量。

1. 显式设置 Title、Heading 1–4 及其基样式的字体槽位、字号、字重和颜色。检查 docDefaults、Normal 和相关链接字符样式的有效继承，不能仅设置高层 font.name 或 color 后就认定覆盖完成。
2. 在相关 w:rFonts 中移除 asciiTheme、hAnsiTheme、eastAsiaTheme、csTheme（按实际属性名识别），再设置配置字体。w:color 保留配置的 val，移除 themeColor、themeTint、themeShade；只设置 val 而保留主题属性仍可能显示蓝色。
3. 清除标题样式及其继承路径中的 w:pBdr、装饰性 w:shd；标题实际段落不得带直接边框或底纹，也不得另插横线、形状或下划线模拟标题分隔。表格三线边框和图片中的学术内容不属于本次清理范围。
4. 标题斜体及其他内置外观不得意外继承，按配置显式初始化。保护正文中的语义斜体、上下标等；不要全局删除 rPr 或 pPr。
5. 在首次保存/导出前，解析最终标题的样式继承与直接格式，确认有效字体符合配置（SimSun 与宋体作为同一字体别名）、有效颜色为配置黑色、没有主题字体/颜色覆盖和段落装饰边框。未通过时在当前构建阶段纠正，不先导出不合格版本。

以上属于首次生成的初始化与检查，不单独创建演示文件、不增加第二份输出，也不为已经通过的结果重复渲染。Word 另存可能将相同属性提升至基样式或使用本地化字体名，QA 应比较有效格式，而不是要求每个样式必须重复保存同一 XML 属性。

## 字体与有效样式

对所有角色在样式层设置 w:rFonts：ascii/hAnsi/cs=Times New Roman，eastAsia=SimSun；中文界面可能显示“宋体”。使用配置值，不靠逐字符拆分语言创建一串新 runs。移除有冲突的 asciiTheme/hAnsiTheme/eastAsiaTheme/cstheme，使主题不覆盖映射；设置适当 w:lang。核对中文、英文、数字和标点的实际渲染。混排映射由 Word 字体槽位执行，不宣称每个 Unicode 字符都会按语言自动选字。

处理 docDefaults、Normal、指定段落/字符样式及正文、表格、页眉页脚、脚注尾注和文本框中的有效字体。w:sz 和 w:szCs 用半磅单位。主题或直接格式可能覆盖样式，QA 必须解析继承及 run/paragraph 覆盖，而非仅查看 style 名。

删除直接格式只能按属性白名单处理：将字体、字号、段距等布局属性归一化，但保护表达学术语义的斜体、加粗、上下标、科学符号和数学对象。不能简单删掉全部 rPr/pPr，不能以 p.text 赋值重建段落。标记语义字重例外并纳入 QA，避免误判标题和科学名词。

公式对象与特殊字符缺字时保留数学字体等必要例外并记录；不要把 Cambria Math 或符号字体强制改为缺字字体。默认字体未安装时先解决可用性，禁止悄悄替代后声称通过。

## 标题与分页

使用内置英文样式名/稳定 styleId，兼容本地化 Word UI。Heading 1–4 分别设 outline level 0–3；标题后跟正文，keep_with_next=true，不能让一条 keep 链持续贯穿整章。不要凭标题文本自动插入、删除或重编号学术章节。

正文 widowControl=true；keepNext=false；keepLines 按配置。对标题、短题注或短表行设置适当保持，不强迫超页长表/长摘要整体留页。节属性需检查全部 sectPr，包括末尾节；横向表格仅在配置允许且确有需要时新建节，并继承页码与必要页眉页脚。

页码使用 PAGE 域。默认无页眉，不生成论文简称或作者信息；双盲稿尤其不得添加身份。保留已有页眉文字的原则仍适用，发现双盲冲突时提出问题。页码重启必须显式配置，检查 first/even/default 页眉页脚关系和 link-to-previous。

## 图片、表格与题注

计算当前节可用宽度=页宽−左右页边距−装订线；多栏时再考虑栏宽与栏间距。检查图片实际 extent、浮动锚点、偏移及裁剪效果；默认采用可行的嵌入型居中显示，但迁移浮动图片前验证不丢失锚定关系。缩放保持比例，可用高度还要考虑题注和上下间距，禁止裁掉学术内容。

表格采用明确 tblW、tblGrid 和单元格宽度，关闭不可控 AutoFit。检查缩进、单元格留白、合并单元格、嵌套表格及当前节边界，不能只看 tblW。三线表仅顶线、表头下线、底线；无竖线、无装饰底色。边框厚度从配置读取，正确换算 OOXML 的八分之一磅。保留必要统计分组线时记录期刊例外。

重复表头用 tblHeader，行高用自动或最小值，禁止会裁切内容的固定行高。短行可禁止拆行；超过一页的单行须允许拆分或采用不改文字的布局修复，不能无限推页。表后必需的 Word 段落是结构节点，不应当作为“空行”无条件删除。

Figure Caption、Table Caption 分别继承 Caption。图题下置：图片所在段 keepNext=true，与下方题注配对，题注自身默认不拉住后文。表题上置：题注 keepNext=true，与表格首行配对。对长题注和复杂跨页对象必须视觉确认。

编号使用真实域，例如 SEQ Figure 或 SEQ Table；引用采用目标书签和 REF，可根据用户现有方案保留 STYLEREF/章节编号。域编号与前缀只替换已识别的显示编号部分，题注说明文字保持原样。书签 ID 唯一、名称合法；既有书签和第三方引用域不得破坏。不要全局正则替换“图 1”或“Table 2”。

设置 updateFields 只代表打开时请求更新，不能证明域已更新。用 Word 或能够正确计算这些域的渲染引擎实际更新正文、页眉页脚等 story 的域，检查 SEQ、REF、PAGE 的缓存显示值及错误信息，再导出 PDF。第三方参考文献管理器域无法安全更新时保留并记录，勿压平成文本。

## 内容保全

建立内容源与生成结果的语义快照，并在每次格式修复前后复核：有序段落文字、单元格及合并关系、脚注尾注、文本框、超链接目标、公式对象、图片资源、批注与修订。直接比较可比较的文字和资源哈希；对被引擎重新序列化的数学/对象比较规范化结构。域结果、分页、样式和经确认的布局填充清理列入独立允许差异表，不把整个文档归一化后忽略变化。出现意外内容差异即回滚对应修改。

若使用 python-docx，认识到高层 API 不覆盖所有 story、域与对象，必要时保留包并定向编辑 OOXML。任何另存工具都应验证不支持对象有没有丢失。不能仅靠正文 text 相等声称论文完整保全。
