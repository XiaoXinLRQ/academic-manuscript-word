# 集中配置契约

assets/manuscript-defaults.json 是通用投稿稿件基线，不代表任何期刊或引用标准的完整官方规范。任务配置深度合并对象；数组整体替换。未知键、负尺寸、缺失样式、未定义继承、继承环或非法枚举应在编辑前报错。所有实际格式值集中存入 resolved-config.json；实现只能读取该文件，不允许在样式创建、分页修复或图表处理函数内另写格式常量。

## 单位与解析

- 字号、段距、绝对缩进、页眉页脚距离、边框及单元格留白使用 pt；纸张和页边距使用 mm；比例使用 0–1。
- line_spacing 使用 mode=multiple 与 value 倍数，或 mode=exact/at_least 与 value_pt 磅数。不要把倍数直接当作磅数。默认倍数行距适应公式；exact 必须检查高字形和公式裁切。
- first_line_indent 使用 unit=character 与 value，或 unit=pt 与 value。character 是 Word 的字符缩进语义，应写 w:firstLineChars，不能以空格或 Tab 代替；若工具不支持，明确记录基于正文有效字号换算的近似。
- hanging_indent_pt 表示悬挂距离，生成 left=该值、firstLine=-该值；不得同时残留冲突的字符缩进。继承时统一清除相互冲突的绝对/字符缩进属性。
- alignment 枚举 left/center/right/justify；outline_level 为 Word 的 0–8，四级标题用 0–3；null 表示普通正文，无大纲级别。
- null 表示显式禁用或无值，不能一律等同“未配置”。base 指样式继承；先解析继承再进行有效格式 QA。

## 覆盖示例与完整性

期刊要求双倍行距时，覆盖 styles.Body Text.line_spacing.value，并核对摘要、引用和题注是否也要求双倍；不要假设所有角色必须同步。所有后续自动修复也只能修改配置再重建，或使用配置已允许的局部修复策略。

只有 references.profile 的切换不应自动改变条目文本或编号。GB/T 7714、APA、IEEE 在这里是可配置体例标签，具体版本、标点、作者规则、排序和引文规则应来自用户提供规范或经核实的官方资料。引用的排序、重编号、字段重写可能改变内容关系，格式任务默认保持。要求完整体例转换时，单独确认内容转换范围，并核对文内引用及条目一一对应；缺少出版信息不得补造。

可针对期刊新增覆盖：页码位置、首页不同、行号、栏数、参考文献字号和悬挂距离、题注前缀、编号方案、图表边距、横向节、长表拆行规则。新格式参数必须加入配置，不能隐藏在代码里。
